# Санал авах 5 асуулт

Demo-г пилот компани болон 5–6 хүнд (анх удаа байр авагч, гадаадад байгаа монгол, хөрөнгө оруулагч) үзүүлсний дараа асууна. Хариуг хүн бүрээр тэмдэглэ.

1. **Итгэл:** Төслийн хуудсыг үзээд энэ хотхон амласан хугацаандаа хүрэх эсэхийг шийдэхэд хангалттай мэдээлэл байна уу? Юу дутуу санагдсан бэ?
2. **Ойлгомж:** Үнийн гурван ангилал, "Хөгжүүлэгч мэдээлсэн / Smartger шалгасан / Баримтаар батлагдсан" шошго, "Олдоогүй" гэсэн бичиг ойлгомжтой байсан уу? Аль нь хамгийн их итгэл төрүүлсэн бэ?
3. **Компанид:** Явцын зураг, зөвшөөрөл, үнийн мэдээллээ сар бүр өгөхөд танд юу хүндрэлтэй вэ? Ямар хэлбэрээр (зураг, файл, утсаар) өгөх нь хамгийн хялбар вэ?
4. **Сарын тайлан:** Гадаадад байгаа худалдан авагчид ийм сарын тайлан хэрэгтэй юу? Юуг нэмж, юуг хасах вэ?
5. **Дараагийн алхам:** Хамгийн түрүүнд юуг өөрчлөх вэ? Энэ бодит болбол та (эсвэл танай компани) хэрэглэх үү, үүний төлөө төлөх үү?
