# Demo-г интернэтэд гаргах заавар (GitHub Pages)

Энэ заавар програмчлал мэдэхгүй хүнд зориулсан. Demo нь **GitHub Pages** дээр үнэгүй байрладаг.

- Demo-н холбоос: https://enkhtuguldur0126-sudo.github.io/smartger-demo/
- Код: https://github.com/enkhtuguldur0126-sudo/smartger-demo

## Яагаад GitHub Pages вэ

- **Үнэгүй.** Нийтэд нээлттэй (Public) сантай бол төлбөргүй.
- **Нэмэлт бүртгэл хэрэггүй.** Код аль хэдийн GitHub дээр байгаа.
- **Автомат.** `main` салбарт өөрчлөлт орох бүрт 1–2 минутын дотор сайт өөрөө шинэчлэгдэнэ (`.github/workflows/deploy.yml`).

**Үнэгүй түвшний нөхцөл (товч):** сайтын хэмжээ 1 GB хүртэл, сард ойролцоогоор 100 GB урсгал. Энэ нь demo-д хангалттай. Онлайн дэлгүүр, төлбөр авах үйлчилгээнд ашиглахыг хориглодог. Энэ demo тийм биш.

**Газрын зураг:** OpenStreetMap-ийн үнэгүй зураг ашигладаг. Нөхцөл нь газрын зургийн буланд "© OpenStreetMap contributors" бичиг байнга харагдах. Энэ бичгийг бүү хас.

## Өдөр тутам: өгөгдөл засах

1. https://github.com/enkhtuguldur0126-sudo/smartger-demo руу орно.
2. `src` → `data` хавтас руу орж засах файлаа дарна (жишээ нь `projects.json`).
3. Баруун дээд талын ✏️ (харандаа) товчийг дарна.
4. Засвараа хийгээд баруун дээд ногоон **Commit changes...** → дахин **Commit changes** дарна.
5. **Actions** таб руу ороход шар дугуй эргэлдэж байна. 1–2 минутын дараа ногоон ✓ болно.
6. Demo-н холбоосыг нээж, утсан дээр бол хуудсаа доош татаж шинэчилнэ.

Анхаар: JSON файлд таслал, хашилт (`"`, `,`, `{ }`) маш чухал. Нэг тэмдэгт дутвал Actions улаан ✗ болж, сайт хуучнаараа үлдэнэ. Тэгвэл засвараа буцаах эсвэл Claude-оос тусламж хүс.

Текстийг `src/i18n/mn.json` (монгол), `src/i18n/en.json` (англи) файлд засна.

## Шинээр тохируулах (шинэ сан үүсгэвэл)

1. GitHub дээр сангийн **Settings** → зүүн цэснээс **Pages**.
2. **Build and deployment** → **Source** гэдгийг **GitHub Actions** болгоно.
3. **Actions** таб → **Deploy to GitHub Pages** → **Run workflow** → ногоон **Run workflow**.
4. 1–2 минутын дараа **Settings → Pages** хуудсын дээд талд сайтын холбоос гарна.

## Асуудал гарвал

| Юу харагдаж байна | Юу хийх |
| --- | --- |
| Actions дээр улаан ✗ | Сүүлийн засварыг шалга (ихэвчлэн JSON-ий таслал). |
| Сайт хуучин харагдана | Утсан дээр хуудсаа шинэчил, эсвэл браузерыг хаагаад дахин нээ. |
| 404 гэсэн хуудас | Settings → Pages → Source = GitHub Actions эсэхийг шалга. |
| Газрын зураг саарал | Интернэт холболтоо шалга. OpenStreetMap түр ажиллахгүй байж болно. |
