# Smartger demo: төслийн товч (BRIEF)

Энэ файлыг Claude Code ажиллахаасаа өмнө бүхлээр нь уншина. Эх баримт Claude Docs дээр байгаа. Энд зөвхөн demo-д хэрэгтэй хэсгийг хуулсан.

## 1. Smartger гэж юу вэ

Монголын шинэ барилгын (баригдаж буй) орон сууцны мэдээлэл ба итгэлийн платформ.

- Хотхон (төсөл) бүр нэг профайл, газрын зураг дээр нэг pin. Нэг хотхонд ~100 орон сууц багцлагдана.
- Ялгарах санаа: **"Зарын сайт биш, төслийн нотолгооны бүртгэл"**. Төсөл бүрийн үнэ, хугацаа, зөвшөөрөл, явц бүр эх сурвалж, огноо, төлөвтэй.
- Нэг өгүүлбэрээр: Hotkhon.mn дууссан хотхон хэдээр зарагдаж байгааг хэлнэ. Smartger баригдаж буй хотхон амласан хугацаандаа хүрэх эсэхийг шалгах боломж өгнө.
- Эхний хэрэглэгчид: анх удаа орон сууц авагч, гадаадад буй монголчууд ба гадаадынхан, хөрөнгө оруулагч.

## 2. Demo-н зорилго

- Пилот компанид 1 сарын дотор үзүүлэх, ажиллаж байгаа мэт харагддаг demo.
- Зөвхөн харагдах хэсэг (front-end). Өгөгдөл JSON файлаас. Сервер, өгөгдлийн сан, нэвтрэлт, админ, AI, мэдэгдэл, төлбөр **байхгүй**.
- Монгол ба Англи хэл. Хятад хэлний файлын бүтэц бэлэн, агуулгагүй.
- Бүх өгөгдөл зохиомол. Бодит компани, хүний нэр, утас, зургийг ашиглахгүй. Зохиомол гэдгийг хуудас бүр дээр тодорхой тэмдэглэнэ.
- Утсанд зориулж эхэлнэ. Android Chrome ба iPhone Safari дээр шалгана.

## 3. Технологи (санал, Claude Code баталгаажуулна)

- Вэб апп, өгөгдөл JSON файлаас. Сервергүй.
- Үнэгүй хостинг (Netlify, Cloudflare Pages, Vercel, GitHub Pages-ээс сонгоно). Үнэгүй түвшний нөхцөлийг шалгана.
- Газрын зураг: Leaflet + OpenStreetMap. Үйлчилгээний нөхцөлд нийцэх эсэхийг шалгана.
- Орчуулга: хэл бүрт тусдаа файл (mn, en, zh).
- Өнгө: CSS хувьсагч. Өдөр/шөнийн горим, утас, компьютерын тохиргоог өгөгдмөлөөр дагана.

## 4. Хуудсууд

1. Нүүр: газрын зураг, төлвийн шүүлтүүр, төслийн жагсаалт. Нүүрэнд "Баригдаж буй төсөл" гол хэсэг.
2. Төслийн хуудас: Тойм, Байр (ээлж, блок, төрөл), Явц, Баримт, Компани, Амлалт.
3. Компаниудын жагсаалт ба компанийн профайл (танилцуулга, хэрэгжиж буй ба дууссан төслүүд).
4. Харьцуулалт: 2–3 байрны төрлийг зэрэгцүүлэх.
5. "Хэрхэн ажилладаг": баталгаажуулалт ба явцын түвшний тайлбар.
6. Хөндийрсөн худалдан авагчийн сарын тайлангийн жишээ хуудас (зөвхөн жишээ, бодит илгээлт байхгүй).

## 5. Өгөгдлийн бүтэц

Зэрэглэл: Компани → Төсөл → Ээлж → Блок → Байрны төрөл.

| Объект | Гол талбарууд |
| --- | --- |
| Компани | id, нэр, лого, танилцуулга (нийтлэл), холбоо барих, баталгаажсан эсэх, өмнө хүлээлгэн өгсөн төслүүд |
| Төсөл | id, нэр, компани, хаяг, координат, төлөв (төслийн шат, баригдаж буй, ашиглалтад орсон), нийт талбай, ногоон байгууламж, нийт айл, зөвшөөрлийн мэдээлэл, албан ёсны данс |
| Ээлж | id, төсөл, айлын тоо, ашиглалтад орох хугацаа |
| Блок | id, ээлж, давхар |
| Байрны төрөл | id, блок, өрөө, м², давхрууд, тагт, цонхны чиглэл, план зураг, үнэ, м² үнэ, төлөв (боломжтой, захиалгатай, зарагдсан), төлбөрийн нөхцөл |
| Явцын бичлэг | id, төсөл, огноо, хувь, юуны хувь, зураг, баталгааны түвшин (1–3), хэн шалгасан |
| Мэдэгдэл (claim) | аливаа тоо, давуу тал бүрт: эх сурвалж (компани, баримт, Smartger), огноо, төлөв (төлөвлөсөн, хийгдсэн) |
| Амлалтын агшин зураг | төсөл анх орох өдрийн үнэ, хүлээлгэн өгөх хугацаа, төлөвлөлт, байгууламжийн амлалт (огноотой, өөрчлөгдөөгүй) |

**Амлалтын нэмэлт талбар:** `амласан хүлээлгэн өгөх хугацаа` ба `одоогийн таамаглал`. Зохиомол өгөгдөлд нэг төслийг хоцорсон, нэгийг хугацаандаа гэж үзүүлнэ.

Талбар хоосон бол "олдоогүй" гэсэн тодорхой төлөвтэй байна. Хоосон үлдээхгүй.

## 6. Үнийн дүрэм

- Гурван ангилал: **Хөгжүүлэгчийн санал**, **Зарын үнэ / жишиг (ҮСХ)**, **Баримтаар батлагдсан хэлцлийн үнэ**. Demo-д эхний хоёр.
- ҮСХ-ийн жишиг үнийг (2026 оны 10-р сар, шинэ орон сууц дунджаар 4.83 сая ₮/м²) эх сурвалжтай нь жишээ болгон харуулж болно.
- AI-аар үнэ таамаглахгүй. Үнэлгээ, N-Estimate төрлийн хэрэгсэл хийхгүй. Амласан ашиг (yield) хэлэхгүй.
- Платформ гэрээ, төлбөр гүйцэтгэхгүй.

## 7. Дизайны дүрэм

- Төслийн хуудас гурван асуултад хариулна: ямар байр байгаа, үнэ хэзээ ба хаанаас гарсан, явц болон баримтыг юугаар шалгах вэ.
- Тоо бүрийн хажууд эх сурвалж, огноо. Мэдээлэл байхгүй бол "Үнэ нийтлээгүй", "Төлөвлөлтийн зураг олдоогүй" гэж бичнэ.
- **Pin:** брэндийн лого. Хэлбэр: зөвхөн хүрээтэй (төслийн шат, суурь цутгахаас өмнө), хагас дүүрсэн (баригдаж буй), бүтэн дүүрсэн (ашиглалтад орсон). Баталгаажсан компанид жижиг тэмдэг. 60 хоногоос дээш шинэчлэлгүй бол бүдэг. Зарагдсан хотхон өгөгдмөлөөр нуугдана. Pin дээр боломжтой байрны тоо. Олон pin давхцвал бөөгнөрнө.
- **Өнгө (Smartger хөх).** Өдөр: дэвсгэр #F6F8FC, гадаргуу #FFFFFF, бичвэр #0B1B33, дэд бичвэр #4A5B78, үндсэн #0060F2, үндсэн дээрх бичвэр #FFFFFF, акцент #0070FB. Шөнө: дэвсгэр #071327, гадаргуу #0E1F3D, бичвэр #E8EEF9, дэд бичвэр #9FB1CF, үндсэн #4D96FF, үндсэн дээрх бичвэр #041229, акцент #6AA9FF.
- Нэмэлт 4 өнгөний загвар логоноос гаргана (тохиргоонд сонгодог).
- Анхааруулгын өнгө (ногоон, шар, улаан) загвараас үл хамааран тогтмол. Бичвэрийн тодосгогч 4.5:1-ээс дээш.
- Баталгаажуулалт 4 түвшин: 1 компанийн тайлан, 2 огноотой зураг, 3 хараат бус инженер, 4 камер/дрон. Demo-д 1–2 л харуулна. Хараат бус инженерийг хэн төлөх нь шийдэгдээгүй, demo-д тайлбарлахгүй.

## 8. Demo-д орох 3 зохиомол төсөл

1. **Бүрэн төсөл:** олон ээлж, блок, байрны төрөл, зөвшөөрөл, албан ёсны данс, явцын зураг, хугацаандаа явж буй.
2. **Хэсэгчилсэн төсөл:** зарим талбар "олдоогүй", нэг ээлж хоцорсон (амласан ба одоогийн таамаглал зөрсөн).
3. **Төслийн шатны төсөл:** хүрээтэй pin, суурь цутгаагүй, зөвхөн төлөвлөгөө.

Нэр нь Smartger-тэй холбоогүй, бодит төсөл, компанитай давхцахгүй зохиомол нэр байна ("Жишээ Компани А" гэх мэт).

## 9. Бүтээх дараалал (долоо хоног бүр)

- **Хэсэг 0 (1–2 хоног):** орчин, хавтасны бүтэц, өгөгдлийн файлын бүтэц, 3 зохиомол төслийн агуулга.
- **1-р долоо хоног:** суурь ба дизайн систем. Хуудасны бүтэц, МН/EN сэлгэх, өдөр/шөнийн горим, өнгөний загвар, өгөгдөл ачаалах.
- **2-р долоо хоног:** компанийн профайл, төслийн жагсаалт, газрын зураг, лого pin, 3 төлөв.
- **3-р долоо хоног:** төслийн хуудас (ээлж, блок, байрны төрөл), гурван үнийн ангилал, эх сурвалж, **амлалтын агшин зураг**, явцын цагийн хуваарь, "олдоогүй" төлөв, харьцуулалт.
- **4-р долоо хоног:** баталгаажуулалтын шошго, **асуулт-хариултын загвар** (зөвхөн дэлгэц, өгөгдөл хадгалахгүй), **сарын тайлангийн жишээ хуудас**, Android ба iPhone дээр шалгах, үнэгүй хостинг дээр гаргах, 5–6 хүнд үзүүлж санал авах.

Demo-д орохгүй (дараа): нэвтрэлт, админ, өгөгдлийн сан, AI ноорог, мэдэгдэл, өвлийн зардлын тооцоо, орчны байдлын давхарга, төрийн холболт, хятад хэлний агуулга, төлбөр.

## 10. Хүлээн авах шалгуур

- **Долоо хоног 1:** төсөл ажиллаж, 3 төсөл газрын зураг дээр pin-тэй гарна, өдөр/шөнийн горим ажиллаж, Монгол ба Англи хэл сэлгэнэ.
- **Долоо хоног 2:** компанийн профайл, жагсаалт, pin-ий 3 төлөв, баталгаажсан тэмдэг, 60 хоногийн бүдэгрэл.
- **Долоо хоног 3:** төслийн хуудас ээлж, блок, байрны төрлөөр харагдаж, харьцуулалт ажиллана. Амлалтын агшин зураг, явцын цагийн хуваарь, "олдоогүй" төлөв, утсан дээр шалгагдсан.
- **Долоо хоног 4:** хостинг дээр ажиллаж байгаа, Android ба iPhone дээр шалгагдсан, бүх хуудас хоёр хэлээр, асуулт-хариулт ба сарын тайлангийн жишээ хуудас байгаа.

## 11. Ажиллах арга (Claude Code-д)

- Би програмчлал мэддэггүй. Эхлээд төлөвлөгөөгөө, шаардлагатай асуултаа надад хэл.
- Алхам бүрийн дараа юуг дарж, юу харагдахыг шалгахыг энгийн монголоор бич.
- Бодит компани, хүний мэдээллийг бүү ашигла.
- Нэг долоо хоногийн ажил дуусмагц шалгуурыг жагсаан хэл, дараа нь л дараагийнхыг эхэл.
