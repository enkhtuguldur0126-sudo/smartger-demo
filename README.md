# Smartger demo

Монголын шинэ барилгын орон сууцны мэдээлэл ба итгэлийн платформын зөвхөн харагдах хэсэг (front-end) demo.
**Бүх өгөгдөл зохиомол.** Бодит компани, төсөл, хүнтэй холбоогүй.

Дэлгэрэнгүй: [docs/BRIEF.md](docs/BRIEF.md), [CLAUDE.md](CLAUDE.md).

## Хавтасны бүтэц

| Хавтас | Юу байгаа |
| --- | --- |
| `src/data/` | Зохиомол өгөгдөл (JSON): компани, төсөл, ээлж, блок, байрны төрөл, явц, мэдэгдэл, амлалтын агшин зураг, жишиг үнэ |
| `src/i18n/` | Хэлний файл: `mn.json`, `en.json`, `zh.json` (хоосон) |
| `src/styles/` | `theme.css`: өнгөний бүх хувьсагч (өдөр/шөнө, 5 загвар). `app.css`: хэлбэр |
| `src/pages/` | Хуудсууд |
| `src/components/` | Дахин ашиглагдах хэсгүүд (толгой, газрын зураг, карт г.м.) |
| `src/lib/` | Өгөгдөл ачаалах, хэл, тохиргоо, чиглүүлэлт |
| `public/` | Лого, дүрс |

## Ашигласан сангууд (бүгд үнэгүй, нээлттэй эх)

- Vite: бүтээх хэрэгсэл
- React: хуудас бүтээх сан
- Leaflet + OpenStreetMap: газрын зураг (© OpenStreetMap эх сурвалжийг заавал харуулна)

## Өөрийн компьютер дээр ажиллуулах (хөгжүүлэгчид)

```
npm install
npm run dev
```
